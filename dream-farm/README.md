# 🌈 Dream Farm（夢想農場）V10.0

一款基於 **Three.js + Vite** 打造的全 3D 休閒經營模擬遊戲，並搭配 **Node.js + Socket.IO** 支援即時多人連線、玩家拍賣行、公會合作社與跨服大型訂單（未啟動後端時亦可完整以單機模式遊玩）。

---

## ✨ 版本演進與核心功能（V1.0 ～ V10.0）

- **🌱 3D 農田耕作與作物突變（V1.0 - V2.0）**：自由種植、澆水加速、收成稱重，並機率觸發「巨型、黃金、彩虹、水晶」等稀有突變加成。
- **🏗️ 網格建造與牧場加工（V3.0 - V4.1）**：自由放置水井、倉庫、雞舍、牛棚與加工工坊；飼養動物、培育好感度繁殖，並將農牧原料加工成高價商品。
- **🌐 多人連線、好友拜訪與自由交易行（V5.0）**：自訂農夫稱號、拜訪在線好友 3D 農場並互助澆水賺取愛心金幣、玩家自由拍賣行上架/競購與世界聊天頻道。
- **🏆 賽季排行榜、全圖鑑與全服活動（V6.0）**：即時計算農場積分 Top 10 排行榜、作物/突變/牧場/加工品全圖鑑進度、自動里程碑成就領獎，以及全服限時增益活動輪替。
- **🌸 四季生態輪替、釣魚池塘與物流無人機（V7.0）**：春夏秋冬動態環境色調與季節增益、3D 石砌池塘拋竿垂釣稀有魚種，以及達倉自動出貨的物流無人機系統。
- **📜 NPC 鎮民委託、科技樹與名聲頭銜（V8.0）**：承接小鎮居民隨機訂單累積名聲晉升頭銜（最高 1.38× 全場售價加成），並研發四大農業科技路線。
- **🏛️ 公會合作社、跨服大訂單與世界奇觀（V9.0）**：建立或加入農夫公會享有全體成員光環、全服共同裝箱遠洋商船大訂單，以及建造「永恆太陽方尖碑」與「生命世界樹聖殿」。
- **🎪 年度農場博覽會評比與農夫換裝（V10.0）**：
  - **農場博覽會評比大賽**：綜合評估農場建築規模、動物數量、圖鑑收集度、名聲與奇觀建設，報名參賽獲取「銅牌～傳奇金獎」獎盃與高額獎金。
  - **農夫外觀造型換裝**：自由解鎖並切換經典農夫裝、皇家金穗禮服、森林遊俠裝與星辰鍊金袍，即時改變 3D 角色造型並附帶專屬被動加成。

## 🚀 本地啟動方式

### 1. 安裝依賴套件
```bash
npm install
```

### 2. 啟動遊戲
- **完整多人連線模式**（建議開啟兩個終端機視窗）：
  ```bash
  # 終端機 1：啟動多人連線、拍賣行與公會伺服器 (Port 3001)
  npm run server

  # 終端機 2：啟動 Vite 3D 前端開發伺服器
  npm run dev
  ```
- **純單機遊玩模式**：只需執行 `npm run dev` 即可直接體驗所有單機經營、博覽會評比、換裝與奇觀建造功能。

## 🎮 操作說明

- **移動角色**：`W A S D` 或方向鍵（支援滑鼠拖曳旋轉視角與滾輪縮放）
- **選擇地塊 / 放置建築**：滑鼠左鍵點擊（建造模式下按 `R` 旋轉方向、`ESC` 或右鍵取消）
- **快捷互動**：`E` 鍵快速種植或收成、`F` 鍵快速澆水
